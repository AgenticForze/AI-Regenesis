## Elevator pitch (1 sentence)

AgenticWorks is the reference architecture library for agentic AI — 60 real use cases across telecom,
financial services, and BSS/OSS, each mapped through an 8-layer framework that goes from a working prototype
to something a regulator, an executive, and an engineer can all trust, with the failure modes included, not
hidden.

## About (3 sentences, for site/LinkedIn bio use)

Most AI use-case libraries are vendor marketing with the mistakes edited out. AgenticWorks is the opposite:
60 multi-agent architectures across telecom, financial services, and BSS/OSS, each one built twice — a Quick
Reference showing the execution pattern, and a Deep 8-Layer view showing the full governed stack — with an
honest retrospective on what broke and what we'd change. Created by Naga Gande, it's built for product
managers who need a fast answer and architects who need the real one.

## Longer positioning paragraph (for an "about" page)

AgenticWorks exists because most "AI architecture" content is either too abstract to build from or too
specific to reuse. This library sits in between: 60 concrete, named use cases across three industries, each
one showing not just *what pattern* to use (orchestrator-worker, pipeline, debate-critique, and five others)
but *what it actually takes* to run that pattern responsibly — governance gates, memory architecture,
observability, and a real build order, not just a diagram. Every use case includes a retrospective section
that says, plainly, what we'd do differently — because the honest failure modes are more useful than another
polished success story. AgenticWorks is built and maintained by Naga Gande around the Regenerative Agentic
Architecture Framework — a methodology for building AI systems that govern, observe, and improve themselves.
