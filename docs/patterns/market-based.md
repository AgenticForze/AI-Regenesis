# Pattern: Market-Based / Auction Agents

Independent agents **bid** for scarce resources (capital, technician time, network capacity) against a **clearing/auctioneer agent** that matches supply and demand. Best for resource-allocation problems with many competing, semi-autonomous stakeholders where a market mechanism adapts faster than centralized scheduling.
