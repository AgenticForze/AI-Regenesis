# Agentic Operations Platform on AWS

The AWS edition of our enterprise Agentic Ops reference architecture: governed AI agents running IT, cloud and business operations on Amazon Bedrock and Bedrock AgentCore, with in-house LLMs and SLMs on EKS for workloads that must stay inside our boundary, and the full AWS network, security and observability estate around them.
