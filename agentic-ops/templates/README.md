# Templates

Reusable building blocks for teams adopting the architecture. All templates are MIT-licensed; copy them freely.

| File | Use it to |
| --- | --- |
| [`agent-spec.yaml`](agent-spec.yaml) | Define an agent's identity, owner, tools, per-action autonomy, budgets, SLOs and evaluation gate |
| [`autonomy-promotion-checklist.md`](autonomy-promotion-checklist.md) | Record the evidence for promoting one action type by one level |
| [`otel-span-schema.md`](otel-span-schema.md) | Instrument agents consistently with OpenTelemetry |
| [`policies/`](policies/) | Start gate G9 with an OPA (Rego) or Cedar action policy |
| [`adr/`](adr/) | Reuse or adapt the architecture decision records |
