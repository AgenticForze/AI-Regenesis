# Phase 16 — Domain Deep Dives: Finance, Healthcare, Telecom

Capstone-depth modules that go beyond the standard 4×3 use-case grid: domain-native regulatory
landscape, core use cases, and domain-specific patterns (TM Forum APIs for Telecom, quant
backtesting for Finance) that don't fit the general concept-chapter template.

- **[Financial Services Agentic AI](/docs/domain-deep-dives/finance)** — SR 11-7 / SEC / MAS,
  plus Research Copilot, Underwriting, Fraud-Investigation, Compliance-Monitoring, and
  Quantitative Backtesting & Algorithmic Execution agents.
- **[Healthcare Agentic AI](/docs/domain-deep-dives/healthcare)** — HIPAA / FDA SaMD / Clinical
  Safety, plus Clinical Documentation, Prior-Authorization, Care-Coordination, and
  Clinical-Trial-Matching agents.
- **[Telecom Agentic AI](/docs/domain-deep-dives/telecom)** — Network-Ops/AIOps, Customer-Care,
  Churn-Prevention, Field-Service Dispatch, TM Forum Open API integration, and Network Slice
  Management & SLA Optimization.
