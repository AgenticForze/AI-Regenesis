# Welcome & How to Use This Knowledge Base

RegAITraining is a continuously growing, GitHub-hosted knowledge base that teaches working
professionals AI from first principles through advanced Agentic AI. It isn't a course you
finish once — chapters are added and revised on an ongoing basis (see the **Recently Added /
Updated** page), and the site is designed to be read non-linearly.

## Two things make this different from a typical tutorial series

**Dual-altitude explanation.** Every concept chapter opens with an intuition-first explanation
a non-specialist can follow (*High-Level Explanation*), then descends into the mechanics — math
where it matters, architecture diagrams, code where useful — for readers who need to build or
defend the concept technically (*Deep-Dive Explanation*). Read only the high-level section if
that's what your role needs; the deep-dive is there when you're ready for it, not a gate you
have to pass through first.

**Domain-grounded, not toy-grounded.** Every applicable chapter carries four worked use cases
apiece in Financial Services, Healthcare, and Telecom — twelve per concept — so a learner in any
of those industries can see the concept solving a problem that looks like their actual job, not
a generic toy example.

## How chapters are structured

Most chapters in Phases 1–8, 10–13, and 15–18 follow the same seven-section template — see
[0.6 The Content Standard, Explained to Learners](./0-6-content-standard-explained.md) for the
full breakdown. Two phases (9 and 14) are deliberately lighter, breadth-first **landscape**
chapters — orientation before the site goes deep elsewhere.

## This site is a work in progress, on purpose

New chapters start from a GitHub issue, get written against the shared chapter template, and go
live the moment they merge — there's no "big launch" being held back. If you find a gap, the
[Contribution Guide](/docs/capstones-and-contributing) explains how to propose and add
a chapter yourself.
