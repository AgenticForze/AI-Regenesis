# Prerequisites Self-Assessment

A quick, honest checklist to figure out where to enter the curriculum. You don't need to check
every box in a section to start there — these are meant to catch the case where you'd be lost on
page one of a phase, not to gatekeep.

## Can I skip straight to Phase 5 (Prompting)?

Check yes if you can comfortably answer:

- [ ] What's the difference between supervised and unsupervised learning?
- [ ] What is a transformer, at a conceptual level (attention, not the math)?
- [ ] What's the difference between a base model and an instruction-tuned model?
- [ ] What does "context window" mean and why does it matter for cost/latency?

All four checked → start at **Phase 5**. Missing one or two → skim **Phase 3–4** first. Missing
most → start at **Phase 1**.

## Can I skip straight to Phase 8 (Agent Foundations)?

Check yes if, in addition to the Phase 5 list above, you can answer:

- [ ] What's the difference between RAG and fine-tuning, and when would you reach for each?
- [ ] What is function/tool calling, at a conceptual level?
- [ ] Have you built at least one working LLM API integration (even a simple chatbot)?

All checked → start at **Phase 8**, use Phase 9's framework landscape as your first stop, and
treat Phase 6/7 as reference material to pull from as needed rather than a required read.

## Can I skip straight to Phase 15/16 (Enterprise / Domain)?

Check yes if:

- [ ] You've designed or operated at least one agentic system with real users or real data.
- [ ] You're comfortable with the four core agentic design patterns (reflection, tool use,
      planning, multi-agent collaboration) — Phase 10.1.
- [ ] You know what a reference architecture diagram for a tool-using agent looks like.

All checked → the **Advanced / Architect Track** (see [0.2](./0-2-learning-paths-personas.md))
is your fastest route in.

## Math background

Phase 1.8 (Math Refresher) exists precisely so you don't need to have this memorized going in —
it's a just-in-time reference, not a prerequisite gate. If you can read a summation and a
gradient-descent update rule without panicking, you have enough to proceed anywhere in the
curriculum and backfill from 1.8 as needed.
